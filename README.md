# Proyecto-BDI-Equipo-40
Sistema Gestor de Reservas, Estadías y Consumos de un Hotel
Introducción

Este proyecto consiste en el diseño de una base de datos para gestionar las principales operaciones de un hotel con restaurante integrado. El sistema permite administrar la información relacionada con los hoteles, habitaciones, tipos de habitación, clientes, reservas, consumos del restaurante, productos, pagos y servicios de mantenimiento.

El proyecto busca organizar y relacionar la información de manera eficiente, permitiendo llevar un control de las reservas y estadías de los clientes, gestionar el stock de productos del restaurante, registrar los consumos realizados y conservar el precio de los productos aplicado al momento de cada consumo.

Además, se contemplan los distintos medios de pago y la posibilidad de realizar pagos parciales, tanto para las reservas como para los consumos. El diseño se desarrolla a partir de las reglas de negocio y restricciones propias del funcionamiento de un hotel, con el objetivo de obtener una estructura de datos organizada, consistente y sin redundancias.
